AgroLingo AI
A beginner-friendly Flask web app prototype for educational maize symptom guidance.
Deploy on Render
Create a Web Service connected to this GitHub repository and use:
Runtime: Python 3
Build command: pip install -r requirements.txt
Start command: gunicorn app:app
Limitations
This is a rule-based educational prototype, not a trained AI model or certified crop diagnostic tool. Review the general symptom guidance against reliable local agricultural sources before real-world use. This prototype does not store user submissions.
